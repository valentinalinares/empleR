# Package index

## Descarga y catalogo

- [`catalogo()`](https://valentinalinares.github.io/empleR/reference/catalogo.md)
  : Ver el catalogo de fuentes disponibles
- [`descargar()`](https://valentinalinares.github.io/empleR/reference/descargar.md)

  : Aplicar etiquetas de valor a variables de la EPEN/EPE

  : Calcular indicadores del mercado laboral con diseno muestral
- [`resumen_nacional()`](https://valentinalinares.github.io/empleR/reference/resumen_nacional.md)
  : Consultar indicadores nacionales pre-calculados (EPEN/ENAHO)

  : Cruzar ocupaciones con el indice de exposicion a inteligencia
